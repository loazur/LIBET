
Mettre ça dans le texte de la commande pour que les joueurs puissent voir les touches correspondantes dans les astuces.

Exemple : "Appuyez sur {ActionName} pour interagir avec les objets." -> "Appuyez sur E pour interagir avec les objets." (si la touche d'interaction est E).



{Interact}	Interagir
{CancelInteraction}	Annuler l'interaction
{Sprint}	Sprinter
{MenuOpenClose}	Ouvrir/fermer le menu
{QuestMenu}	Menu des quêtes
{NotesMenu}	Menu des notes
{Move}	Se déplacer
{Look}	Regarder
