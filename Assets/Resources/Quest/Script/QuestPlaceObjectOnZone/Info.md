

Sur l'objet qui sera la zone où doivent être placés les objets, mettre le tag "QuestZone" et y ajouter le script S_QuestZone.
Ensuite sur le script de quête, il faut juste choisir entre :
- Utiliser le tag "QuestZone" pour valider (recommandé)
- Ou bien choisir manuellement la zone dans le paramètre "targetZoneParameter" (moins recommandé mais plus précis)
